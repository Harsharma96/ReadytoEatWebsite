# 🎨 FoodEat™ Frontend Application

Awwwards-Winning Luxury Food Experience built with Next.js 14, Tailwind CSS, Framer Motion, and GSAP.

## 🌟 Pages
- `/` — Living Universe Home (Hero, 3D Dish Showcase, Bento Story, Live Order Confirmation)
- `/menu` — Dedicated Gourmet Culinary Menu (Filters & Search)
- `/about` — Why FoodEat Michelin Story
- `/trending` — Trending Plates Masonry Gallery
- `/box` — Custom 4-Pack Feast Box Builder
- `/contact` — VIP Chef Concierge & Catering Booking
- `/track/[id]` — Real-Time Animated GPS Satellite Radar Map
- `/admin` — Executive Admin Terminal (Full CRUD Operations)

## 🛠️ Run Frontend
```bash
npm install
npm run dev
```
Runs on `http://localhost:3000`.
